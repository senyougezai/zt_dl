# Zeta Chat Backup Tool (Zeta 会話ログ一括保存拡張機能)

Zeta（ブラウザ版）の会話ログを一括で取得し、時系列順に並び替えたテキストファイル（.txt）としてローカルに書き出す Chrome / Edge 向けブラウザ拡張機能です。

サービス側のデータ整理やトーク削除に備えた、個人のバックアップ用途として作成されています。

---

## ✨ 主な機能

- **ワンクリック自動認識**: 開発者ツール（F12）を開かずに、認証TokenとルームIDを自動取得。
- **ユーザー名の自由設定**: 保存テキスト内の「あなた」の表記を好きな名前（自キャラ名など）に変更可能。
- **取得件数の指定**: 全件（最大10,000件）または最新N件のみの切り出しに対応。
- **会話構造の完全再現**: ナレーター描写や連続セリフも抜け漏れなく時系列順に復元。
- **ローカル完結の安全性**: 外部サーバーへの通信は一切行いません。

---

## 📥 インストール方法（Chrome / Edge）

1. 画面右側の **[Releases]** から最新の `zeta-backup-extension.zip` をダウンロードし、解凍します。
2. ブラウザのアドレスバーに以下を入力して開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
3. 画面右上の **「デベロッパー モード」** をオンにします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダを選択します。

---

## 🚀 使い方

1. ブラウザ版 Zeta で保存したいトークルームを開きます。
2. 画面右下に表示される **「📥 ログ保存」** ボタンをクリックします。
3. ポップアップ画面で「表示名」と「取得件数」を確認・変更し、**「ダウンロード開始」** を押します。
4. 整形済みのテキストファイル（`.txt`）が自動でダウンロードされます。

> ※ボタンを押した際に「認証キーを認識中」と表示された場合は、チャット画面を少し上にスクロールして過去ログを1度読み込ませてから再度お試しください。

- **オープンソース**: すべてのスクリプトは本リポジトリで公開されており、検証可能です。
